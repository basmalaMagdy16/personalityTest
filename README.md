# Personality AI Test API

## 🧠 Overview
This project is a **Personality Test AI API** that predicts the MBTI personality type based on user responses to a questionnaire.  
It also provides a **summary of the personality** and **suggested careers** suitable for each type.

The AI model is built with **Python** and deployed using **Flask**. The project is hosted on **Microsoft Azure**.

---

## 🔹 Features
- Predict MBTI personality type from user answers.
- Return a personality summary.
- Suggest suitable careers for the predicted personality.
- JSON-based API for easy integration with frontend applications.

---

## 🛠 Tech Stack
- **Python 3.x**  
- **Flask** – Web framework for API  
- **Joblib** – Model serialization  
- **Pandas** – Data processing  
- **Azure** – Cloud hosting  
- **GitHub** – Version control
